# 출판 전환 계획

## 기본 방향

게임은 플레이어가 태도를 선택하는 작품이고, 소설은 인물이 왜 그런 선택밖에 하지 못했는지 끝까지 따라가는 작품이다. 따라서 게임 대사를 그대로 이어 붙이지 않고 정사 루트를 중심으로 다시 집필한다.

## 소설판 권장 구조

| 부 | 내용 | 예상 분량 |
|---|---|---:|
| 1부 늦은 비 | 첫 만남, 일상 교류, 첫 데이트 | 20,000자 |
| 2부 두 사람의 달력 | 연애 시작, 100일, 가족 소개 | 25,000자 |
| 3부 굳은살 | 생업과 간병 충돌, 과잉 돌봄, 이별 | 25,000자 |
| 4부 다시 봄 | 분리된 성장, 재회, 생활 합의 | 25,000자 |
| 에필로그 | 첫 만남 1주년 | 5,000자 |

## 게임 요소의 소설 변환

| 게임 요소 | 소설 표현 |
|---|---|
| 호감도 상승 | 먼저 연락하는 빈도, 시선이 머무는 시간 |
| 신뢰 상승 | 아픈 모습, 돈 문제, 가족 이야기를 먼저 꺼냄 |
| 존중 상승 | 도움 전에 묻기, 거절 뒤 물러나기 |
| 서운함 누적 | 짧아진 답장, 치우지 않은 컵, 피한 호칭 |
| 플래그 | 반복 소품과 이전 대사의 변주 |
| 선택지 | 망설임과 선택하지 않은 행동의 잔상 |

## 시점

- 기본: 민우와 서정의 3인칭 제한 시점을 장별로 교차
- 같은 사건을 두 번 반복하지 않는다.
- 시점이 바뀔 때 독자가 새 사실이나 오해의 원인을 알게 해야 한다.
- 지은과 도윤은 외전 주인공이 될 수 있으나 본편에서는 독립된 욕망을 가진 조연으로 유지한다.

## 권리와 기록 관리

- 인물명, 설정, 초고 변경 이력을 날짜와 함께 보관한다.
- 사용한 폰트, 음악, 이미지, 플러그인의 라이선스를 별도 표로 기록한다.
- Godot 배포물의 크레딧에는 엔진의 저작권 고지와 MIT 라이선스 안내를 포함한다.
- 출판 계약 전에는 게임판과 소설판의 2차적 저작물, 전자책, 오디오북, 해외 번역권 범위를 확인한다.
- 실제 간병·이혼·양육 사례를 참고할 때는 식별 가능한 개인정보를 사용하지 않는다.

## 집필 완료 기준

1. 주인공 두 사람의 욕구와 두려움이 각 장면에서 행동으로 보인다.
2. 갈등이 단순한 오해가 아니라 가치와 자원의 충돌에서 나온다.
3. 새 인연이 기존 관계를 자극하기 위한 장치로만 남지 않는다.
4. 결말에서 사랑뿐 아니라 일, 가족, 건강의 변화도 마무리된다.
5. 게임 정사와 소설 설정표의 나이·가족·시간선이 일치한다.
