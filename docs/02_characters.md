# 등장인물 설정

## 관계 설계 원칙

- 모든 주요 연애 후보는 40세 이상이다.
- 결혼 경험과 자녀 유무는 성격을 설명하는 하나의 조건이지 인물의 등급이 아니다.
- 각 인물은 `받고 싶은 돌봄`, `건넬 수 있는 돌봄`, `돌봄으로 위장한 통제`를 모두 가진다.
- 누군가와 연애하지 않는 엔딩에서도 인물의 삶은 계속된다.
