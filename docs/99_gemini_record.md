## 기록에 있던 요청 흐름

1. Godot 공식 사이트 요약과 1인 개발 관점의 장점
2. GDScript와 C# 비교
3. 40대 이상 중년 로맨스 게임 시나리오 요청
4. 돌싱·미혼·자녀 유무를 반영한 인물 설정 요청
5. 호감도·피로도·스트레스와 선택지 구조 요청
6. 제1장 소설 본문과 Godot용 게임 대본 요청

## 유지한 핵심 아이디어

- 목공방 운영자 강민우와 북카페 매니저 겸 번역가 윤서정
- 생강차와 미닫이문 수리로 시작하는 첫 만남
- 행동형 돌봄과 정서형 돌봄의 상호 교환
- 100일 기념일을 둘러싼 현실적인 온도 차
- 부모 간병, 자녀, 생업, 건강 문제가 동시에 겹치는 갈등
- 이별 뒤 재회 또는 새로운 만남으로 이어지는 분기
- 호감도, 피로도, 스트레스의 상태 시스템
- GDScript 우선 개발 방향

## 이번 정리에서 보완한 점

- 돌봄을 성별 고정 역할이 아닌 상호적인 관계 기술로 재정의했다.
- 애정 외에 신뢰, 존중, 서운함을 추가해 `잘 챙겨주기만 하면 성공`하는 구조를 피했다.
- 민우·서정뿐 아니라 지은·도윤·수현에게도 독립된 욕구와 경계를 부여했다.
- 출판판 정사와 게임 분기의 관계를 명시했다.
- 5장 개요를 7개 섹터로 확장해 실제 제작 단위로 쪼갰다.
- Godot 공식 사이트의 현재 안내와 라이선스 주의점을 별도 문서로 정리했다.
