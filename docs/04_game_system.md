# 게임 시스템 기획

## 1. 플레이 루프

한 주는 `평일 사건 → 저녁 연락 → 주말 행동 → 관계 정산`으로 진행된다.

1. 평일 사건에서 생업·가족·건강 변수 발생
2. 메시지 또는 통화에 어떻게 반응할지 선택
3. 주말에 데이트, 돌봄, 휴식, 일 중 하나를 선택
4. 관계 수치와 개인 상태가 변하고 다음 에피소드가 해금

## 2. 핵심 상태값

### 관계 상태

| 상태 | 범위 | 의미 |
|---|---:|---|
| 애정 `affection` | 0~100 | 함께 있고 싶은 감정 |
| 신뢰 `trust` | 0~100 | 약속과 취약함을 맡길 수 있는 정도 |
| 존중 `respect` | 0~100 | 상대의 선택과 경계를 인정하는 정도 |
| 서운함 `resentment` | 0~100 | 말하지 못한 기대와 반복된 실망 |

### 개인 상태

| 상태 | 범위 | 의미 |
|---|---:|---|
| 피로 `fatigue` | 0~100 | 신체 자원 고갈 |
| 스트레스 `stress` | 0~100 | 정서적 압박 |
| 생활안정 `stability` | 0~100 | 일, 돈, 가족 일정의 균형 |

애정만 높아도 좋은 엔딩에 도달할 수 없다. `신뢰`와 `존중`이 낮거나 `서운함`이 높으면 강한 애정은 집착과 반복 재회로 바뀐다.

## 3. 돌봄 선택의 네 유형

| 유형 | 예시 | 일반 효과 |
|---|---|---|
| 경청 | “해결책이 필요해요, 아니면 그냥 들어줄까요?” | 신뢰 +, 스트레스 - |
| 실질 지원 | 병원 동행, 가게 마감 도움 | 피로 +, 애정 + |
| 경계 존중 | 도움 제안 후 거절 수용 | 존중 ++ |
| 과잉 개입 | 허락 없이 일정·돈·가족 문제 처리 | 단기 안정 +, 존중 --, 서운함 + |

돌봄은 무조건 좋은 버튼이 아니다. 자신의 피로가 80 이상인데 계속 상대를 돕는다면 `희생 누적` 상태가 생기고, 이후 작은 사건에도 폭발할 수 있다.

## 4. 대화 선택 구조

선택지는 선악 대신 태도를 고른다.

```text
서정: “엄마가 또 집을 나가려고 했어요. 오늘은 정말 겁났어요.”

A. “지금 갈게요. 주소 보내요.”                 [즉시 행동]
B. “내가 뭘 해주면 제일 도움이 될까요?”          [요구 확인]
C. “이제 시설을 알아봐야 하는 거 아니에요?”       [해결 제안]
D. “나도 오늘 공방 계약 때문에 정신이 없어요.”    [자기 한계]
```

상황과 이전 선택에 따라 같은 답의 효과가 달라진다. 예를 들어 D는 무례한 회피가 될 수도 있지만, 이전에 한계를 솔직히 말해온 플레이어라면 신뢰를 지키는 선택이 될 수 있다.

## 5. 기념일 시스템

기념일은 돈을 많이 쓰는 시험이 아니라 `기억`, `취향 이해`, `현실 조율`을 확인하는 사건이다.

- 100일: 관계를 어떻게 정의하는지 확인
- 생일: 상대가 받고 싶은 방식과 가족 일정을 존중하는지 확인
- 첫 만남 1주년: 엔딩 후일담에서 반영

기념일 준비 점수:

```text
준비도 = 기억 40% + 취향 이해 30% + 일정 배려 20% + 비용 적합성 10%
```

비싼 선물도 상대 취향과 재정 상태를 무시하면 역효과가 난다. 작은 선물도 과거 대화에서 얻은 정보를 반영하면 특별 장면을 해금한다.

## 6. 갈등과 회복

### 갈등 발생 조건 예시

- 스트레스 80 이상 + 서운함 50 이상
- 약속 위반 태그 2회 누적
- 가족 경계 침범 태그 보유
- 중요한 대화 3회 회피

### 회복의 네 단계

1. 멈춤: 당장 결론 내리지 않고 감정 온도 낮추기
2. 사실: 무엇이 있었는지 과장 없이 말하기
3. 영향: 상대에게 어떤 감정과 비용을 만들었는지 인정하기
4. 합의: 다음번에 바꿀 구체적인 행동 정하기

사과 문구 하나로 관계가 복구되지 않는다. `합의` 이후 비슷한 사건에서 행동이 달라져야 신뢰가 회복된다.

## 7. 일정과 현실 사건

매주 행동 포인트는 3이다.

- 일: 생활안정 +, 피로 +
- 가족: 가족관계 +, 스트레스 변동
- 연애: 애정 +, 일정 충돌 가능
- 휴식: 피로·스트레스 -
- 혼자만의 시간: 자기이해 플래그 해금

모든 영역을 완벽히 지킬 수 없게 설계하되, 특정 선택을 벌주기보다 무엇을 우선했는지 다음 대화에 반영한다.

## 8. 엔딩 판정 개요

```text
재회·동행:
affection >= 70, trust >= 65, respect >= 65,
resentment <= 35, 합의실천 >= 2

불안한 재결합:
affection >= 75, trust < 50 또는 respect < 50

성숙한 이별:
trust >= 50, 자기이해 플래그 >= 3, 이별대화 완료

새로운 만남:
기존 관계 정리 완료 + 상대 후보 신뢰 >= 60

홀로서기:
자기돌봄 플래그 >= 4, 생활안정 >= 60
```

## 9. 데이터 구조 초안

```gdscript
class_name RelationshipState
extends Resource

@export_range(0, 100) var affection: int = 0
@export_range(0, 100) var trust: int = 0
@export_range(0, 100) var respect: int = 0
@export_range(0, 100) var resentment: int = 0
@export var flags: Dictionary = {}
```

시나리오 데이터는 코드와 분리한다. 대사 본문, 화자, 표정, 배경, 선택지, 조건, 효과를 별도 데이터 파일로 관리해야 출판 원고 수정과 게임 구현이 서로 방해하지 않는다.
