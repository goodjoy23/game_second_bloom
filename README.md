# 《오후 네 시, 다시 봄》

40대 이후의 사랑을 다루는 선택형 3D 탐색 비주얼 노벨 프로젝트입니다. 서로를 돌보는 기쁨뿐 아니라 부모 간병, 자녀, 생업, 건강, 돈, 혼자 살아온 습관처럼 중년의 연애가 실제로 마주하는 문제를 함께 다룹니다.

게임의 핵심 질문은 하나입니다.

> 사랑은 상대의 삶을 대신 짊어지는 일일까, 아니면 각자의 삶을 존중하며 곁을 내어주는 일일까?

이 저장소에는 같은 주제를 다루는 두 작품이 함께 있습니다. 하나는 플레이어가 태도를 선택하는 게임판이고, 다른 하나는 두 사람이 같은 하루를 각자 기록해 교차로 엮은 소설판입니다.

## 현재 기획 기준

- 엔진: Godot 4.x
- 언어: GDScript 우선
- 형식: 3D 공간 탐색 + 근접 말풍선 대화 + 관계 상태 변화
- 1차 주인공: 강민우(46세, 돌싱, 비양육 자녀 있음)
- 중심 상대역: 윤서정(44세, 미혼, 자녀 없음)
- 플레이 관점: 민우 시점으로 시작하고, 주요 장면에서 서정의 시점을 해금
- 출판 기준 정사: 민우와 서정의 관계를 중심으로 한 문학적 재구성
- 게임 분기: 재회, 성숙한 이별, 새로운 만남, 자발적 홀로서기

## 저장소 구조

```text
.
├─ games/   Godot 게임 프로젝트, 에셋, 시나리오와 검증 도구
├─ data/    제1장 대화 데이터
├─ docs/    게임 기획 문서와 캐릭터 시트
└─ novel/   소설판 기획 문서와 원고
```

게임과 소설은 같은 주제를 공유하지만 구현물과 원고를 분리해 관리한다. Godot 프로젝트 루트는 저장소 루트가 아니라 `games/`이며, 게임 실행과 검증 명령도 이 폴더를 기준으로 한다.

## 소설판 《우리는 같은 날을 다르게 적었다》 (가제)

이창근과 이인선이 같은 하루를 각자 1인칭으로 기록하고, 두 기록을 교차 배열해 한 권으로 합치는 작품이다. 원고와 기획 문서는 [novel/](novel/README.md) 아래에 있다.

- 남자 화자: 이창근 — 50대 초반, 화자 "나"
- 여자 화자: 이인선 — 48세, 직장인
- 구성: 15상황 × 2시선 = 30편 + 어긋남 노트 15편, 프롤로그와 에필로그 포함 약 10만~11만 5천 자
- 형식: 소설과 에세이의 중간. 실제 감정을 소재로 하되 인물·지명·직장은 변형한다
- 목표: 교보문고 퍼플 전자책 무료 출간, 2026년 12월

### 이 작품의 구조

모든 회차는 한 쌍이다. 사실은 하나이고, 달라지는 것은 무엇을 기억했는가와 무엇을 말하지 않았는가뿐이다.

```text
[상황 01] 앱에서 먼저 말을 건 날
  ├─ a 창근의 시선 : 나이, 지역, 자녀 상황. 조건 세 가지를 보고 먼저 말을 걸었다
  ├─ b 인선의 시선 : 술김에 만든 계정이었다. 누굴 만나려고 거기 있던 게 아니었다
  ├─ c 여백 페이지 : 두 편 모두에 나온 문장 한 줄
  └─ d 어긋남 노트 : 왜 그렇게 읽혔는지와, 그때 쓸 수 있었던 문장
```

젊은 연애 소설은 무슨 일이 일어났는가로 읽히고, 중년 연애 소설은 같은 일을 왜 다르게 읽었는가로 읽힌다. 독자는 창근 편에서 자기를 보고, 인선 편에서 자기 상대를 보고, 어긋남 노트에서 그래서 무엇을 할지를 가져간다.

### 집필 규칙

- 두 편의 사실은 절대 어긋나지 않는다. 날짜·장소·오간 대사·소품은 [사실 대장](novel/03_사실대장.md)에 먼저 적고 두 편이 그것을 참조한다.
- 대사는 토씨까지 같게 쓴다. 같은 대사가 다른 무게로 읽히는 것이 이 책의 기술이다.
- 창근은 짧은 문장으로 행동과 사실을 먼저 적고, 인선은 긴 문장으로 감각과 기억을 먼저 적는다.
- 어느 편을 읽어도 그 화자가 옳게 느껴져야 한다. 한쪽이 가해자로 읽히면 그 회차는 다시 쓴다.
- 실존 인물을 모델로 하는 부분은 동의를 문서로 남기고, 동의를 받을 수 없는 제3자는 반드시 픽션화한다.
- 어긋남 노트는 두 편이 확정된 뒤에 쓴다. 진단하지 않고, 확신이 서지 않는 개념은 빼고 관찰만 남긴다.

### 게임판과의 관계

소설판의 이창근·이인선은 게임판의 강민우·윤서정과 인물명과 설정이 다르다. 현재는 두 작품을 분리해 운영하며, 통합 여부는 소설판 출간 후에 결정한다.

## 게임 실행 방법

이 프로젝트는 Godot 4.x에서 실행한다. 현재 개발 환경에서 확인한 엔진 버전은 Godot 4.7.2다.

### Godot 에디터에서 실행

1. Godot을 실행하고 `가져오기(Import)`를 선택한다.
2. `games/project.godot` 파일을 선택한다.
3. 프로젝트가 열리면 `F5` 또는 오른쪽 위의 프로젝트 실행 버튼을 누른다.
4. 시작 화면에서 플레이할 캐릭터를 선택한다.
5. 방향키 `← ↑ ↓ →`로 선택한 캐릭터를 움직인다. 캐릭터는 걷는 방향으로 자연스럽게 회전한다.
6. 다른 캐릭터에게 가까이 가면 해당 인물 근처에 말풍선 대화가 자동으로 시작된다.
7. 주요 이야기 대화는 `스페이스바`로 진행한다. 대답이 나타나면 `↑/↓`로 선택하고 `스페이스바`로 전달하며, 일반 NPC는 자동으로 응답한다.

북카페는 실제 3D 공간과 충돌체로 구성되어 있다. 벽과 창문 경계, 테이블, 카운터, 책장, 화분은 통과할 수 없으며 가구 사이의 열린 통로로 이동해야 한다.

선택 화면과 이름표에서 남성은 청색 `[남]`, 여성은 장미색 `[여]` 표식으로 구분한다. 동성 인물끼리는 동료 대화를 나누고, 남녀 인물은 각자의 시점에 맞는 첫 만남 대화를 시작한다. 윤서정을 선택해 강민우와 대화를 이어가면 여성 시점의 첫 인사 뒤 제1장 시나리오로 연결된다.

현재 개발 PC에서는 다음 PowerShell 명령으로 에디터를 바로 열 수 있다.

```powershell
& "D:\utils\Godot_v4.7.2\Godot_v4.7.2-stable_win64.exe" --editor --path "D:\게임\중년의연애소설\games"
```

에디터를 거치지 않고 게임을 바로 실행하려면 다음 명령을 사용한다.

```powershell
& "D:\utils\Godot_v4.7.2\Godot_v4.7.2-stable_win64.exe" --path "D:\게임\중년의연애소설\games"
```

다른 환경에서는 위 경로를 각자의 Godot 실행 파일과 `games/` 폴더 경로로 바꾸면 된다. 자세한 현재 구현 범위와 게임 내부 파일 구조는 [게임 시작 안내](games/GAME_START.md)를 참고한다.

> **데이터 경로 확인 필요:** 현재 제1장 데이터는 저장소 루트의 `data/chapter_01.json`에 있지만, 게임 코드와 검증 스크립트는 Godot 리소스 경로 `res://data/chapter_01.json`, 즉 `games/data/chapter_01.json`을 읽는다. 게임을 실행하거나 검증하기 전에 데이터 위치를 게임 프로젝트 구조와 맞춰야 한다.

### 챕터 데이터 검증

제1장 데이터의 중복 ID와 끊어진 대화 연결은 다음 명령으로 검사한다.

```powershell
& "D:\utils\Godot_v4.7.2\Godot_v4.7.2-stable_win64_console.exe" --headless --path "D:\게임\중년의연애소설\games" --script "res://tests/validate_chapter.gd"
```

정상이면 `Chapter validation passed: 27 nodes`가 출력된다.

3D 충돌, 이동 방향 회전, 근접 대화, NPC 움직임은 다음 명령으로 함께 검사할 수 있다.

```powershell
& "D:\utils\Godot_v4.7.2\Godot_v4.7.2-stable_win64_console.exe" --headless --path "D:\게임\중년의연애소설\games" --script "res://tests/validate_exploration.gd"
```

## 작업 원칙

- 돌봄은 성별 역할이 아니라 두 사람이 서로 배우는 사랑의 언어로 쓴다.
- 큰 사건보다 밥, 약, 귀가, 수리, 병원 대기실 같은 생활 장면에서 감정을 드러낸다.
- 선택지는 정답 찾기가 아니라 가치관의 비용을 선택하는 구조로 만든다.
- 이혼, 비혼, 자녀 유무를 결핍이나 벌로 취급하지 않는다.
- 간병과 건강 문제를 사랑의 시험 도구로만 소비하지 않는다.
- 게임 원문과 출판 원고를 분리해 관리하되 인물의 사실관계는 프로젝트 바이블을 기준으로 통일한다.
