# 내가 할 일 — 단계별 체크리스트

기준일 2026-08-26. 주 3편(약 9,000자) 페이스, 총 17주 → **2026년 12월 넷째 주 출간** 목표.
집필 시간이 주 2회밖에 안 나오면 초고를 15주로 늘리고 출간을 2월로 민다. 페이스를 줄일지언정 건너뛰지 않는다.

## 잔여 작업

지금 열려 있는 작업. 끝나면 아래 단계별 목록으로 옮긴다.

- [ ] **이인선 캐릭터 시트 완성** — [docs/캐릭터/이인선.md](../docs/캐릭터/이인선.md)
  - 파일을 본인과 공유하고 `(본인 작성)` 칸을 본인이 채운다: 혼인·자녀, 가족, 건강, 겉모습과 습관, 내면 욕구, 받고 싶은 돌봄, 받고 싶지 않은 돌봄, 대표 소품, 말버릇, 결정적 대사
  - `(임시)` 칸 다섯 개를 본인 확인 뒤 확정하거나 교체한다: 직업, 사랑의 언어, 내면 두려움, 결함, 변화
  - 창근 쪽에서 임의로 채우지 않는다. 상상으로 메운 내면은 원고에서 그대로 티가 난다
  - 시트가 비어 있으면 인선 시점 15편의 초고를 시작하지 않는다
- [ ] **픽션화 목록 확정** — 직장명, 직급, 동네, 가족 나이와 병명, 학교 중 최소 셋을 실제와 다르게 정한다
- [ ] **동의 문서 작성** — 출간 형태, 판매 여부, 필명 범위
- [ ] **2부 이후 목차 교체** — 상황 06~15가 아직 게임판에서 가져온 임시 구성이다. 실제 6년의 사건으로 바꾼다
- [ ] **어긋남 노트 개념 배정 확인** — [설계 문서](06_어긋남노트_설계.md)의 개념 후보표를 상황별로 확정하고, 확신이 서지 않는 개념은 뺀다

- [x] 게임판 인물명과 통합할지 분리할지 결정 — **분리 유지.** 소설판 이창근·이인선은 게임판 강민우·윤서정과 별개 정사다
