# 출판 계획 — 교보문고 무료 출간

> **먼저 확인할 것**: 아래 절차와 규격은 자가출판의 일반 실무 기준이다.
> 요율·판형·심사 기간 같은 수치는 정책이 바뀌므로 **등록 직전에 아래 두 곳에서 직접 확인**한다.
> - 퍼플(PubPle) — `pubple.kyobobook.co.kr`
> - 교보문고 바로출판 POD — `store.kyobobook.co.kr/pod`
> 조회 시점(2026-08) 기준으로 두 서비스 모두 운영 중이나, 공개 페이지에 세부 규격이 노출되지 않아 고객센터 확인이 필요하다.

## 1. 어디까지가 "무료"인가

| 항목 | 비용 |
|---|---|
| 회원가입 · 판매자(저자) 등록 | 무료 |
| **eBook(ePub/PDF) 등록·심사·판매** | **무료** ← 이 책의 1차 목표 |
| ISBN 발급 (자가출판용) | 무료 |
| 종이책 POD **등록** | 무료 |
| 종이책 **실물 인쇄** | 유료 (부수만큼 인쇄비, 저자 증정본도 저자 부담) |
| 표지 디자인 · 교정 · 조판 대행 | 유료 옵션 (직접 하면 0원) |

**결론: 전자책만 내면 총비용 0원.** 종이책은 "등록해두고, 팔릴 때 찍히고, 내가 갖고 싶을 때만 사는" 구조로 두면 된다.
인세는 통상 저자 몫이 더 큰 구조(약 6:4 수준)로 안내되어 왔으나, 계약 화면에서 실제 요율을 확인한다.

## 2. 전체 흐름

```
원고 완성
   └─ 교정·교열 (2회)
        └─ 조판 (한글/워드 → PDF) + 표지 제작
             └─ 퍼플 가입 → 판매자 승인
                  └─ 도서 정보 입력 (제목/저자/소개/키워드/가격)
                       └─ 원고·표지 업로드
                            └─ 심사 (영업일 며칠 소요)
                                 └─ 판매 개시 → 교보 eBook 앱·웹 노출
```

## 3. 원고 규격 (실무 기준)

### 전자책 — ePub 권장

- 퍼플의 **ePub 에디터**로 직접 만들거나, 완성된 ePub 파일을 올린다.
- **소설·에세이는 반드시 리플로우형(ePub)** 으로. PDF 전자책은 휴대폰에서 글자가 작아 읽히지 않고, 중년 독자층에서 특히 치명적이다.
- 구조: 표지 → 서지 → 목차 → 프롤로그 → 본문(상황 01~15) → 에필로그 → 작가의 말
- 각 편은 **개별 챕터로 분리** (목차에서 "01 창근", "01 인선"이 각각 잡히도록)
- 글꼴은 지정하지 말고 독자 설정을 따르게 둔다.

### 종이책 — PDF

| 항목 | 권장값 |
|---|---|
| 판형 | A5 148×210 또는 신국판 152×225 |
| 여백 | 안쪽 20mm / 바깥 16mm / 위 20mm / 아래 22mm |
| 본문 | 10~10.5pt, 행간 170~180%, 양쪽 정렬 |
| 폰트 | 본문 명조 계열. **상업 사용 가능 무료 폰트**만 (KoPub 바탕, 나눔명조, 본명조/Noto Serif KR). 각 폰트의 허용 범위를 캡처해 보관 |
| 파일 | PDF, 폰트 임베딩 필수, 단면 페이지, 재단선 여부는 규정 확인 |
| 페이지 | 짝수로 맞춘다. 부 시작은 홀수 쪽에서 |

### 표지

- 전자책: 앞표지 1장 (JPG/PNG, 세로 긴 비율, 긴 변 1,500px 이상)
- 종이책: 앞 + 책등 + 뒤 **한 장짜리 통합 PDF**. 책등 두께 = 쪽수 × 종이 두께(인쇄 규격에 따라 산출) → 조판 확정 후 계산
- 이미지 소스: 직접 촬영 / 상업 이용 가능 라이선스만. **AI 생성 이미지를 표지에 쓸 경우 해당 서비스의 상업 이용 약관과 교보의 정책을 둘 다 확인**
- 표지 문구: 제목 / 부제 / 저자명(필명 가능)
- 뒤표지: 4~5줄 카피 + 본문 인용 두 줄(창근 한 줄, 인선 한 줄) ← 이 책은 뒤표지에서 컨셉이 바로 보인다

## 4. 등록 정보 (판매 페이지에서 팔리는 부분)

| 항목 | 작성 지침 |
|---|---|
| 카테고리 | 소설 > 한국소설 (에세이로 갈지 결정: **소설로 내는 쪽이 안전**하다. 에세이는 사실로 읽혀 실존 인물 리스크가 커진다) |
| 저자명 | 필명 권장. 실명은 검색으로 두 사람이 특정될 수 있다 |
| 책 소개 | 첫 3줄에 컨셉을 박는다: "같은 하루를 두 사람이 각자 적었다. 남자의 기록과 여자의 기록은, 같은 날이 아니었다." |
| 키워드 | 중년로맨스, 40대연애, 50대연애, 재혼, 돌싱, 교차시점, 부부, 황혼연애, 에세이소설 |
| 가격 | 전자책 3,900~6,500원대. 첫 책은 **4,500원 전후**가 무난 |
| 미리보기 | 프롤로그 + 상황 01 두 편(창근·인선) 전체를 연다. **반드시 쌍으로** 열어야 컨셉이 전달된다 |

## 5. 출간 전 필수 점검

- [ ] 이인선 모델이 된 실존 인물의 **서면 동의** (형태·판매·필명 범위 명시)
- [ ] 제3자(전 배우자·자녀·부모·직장) 식별 정보 픽션화 완료
- [ ] 판권면에 저작권 표시, 발행일, 발행처(자가출판), ISBN
- [ ] 인용한 노래 가사·시·타인 문장 **전부 삭제 또는 출처 표기 후 허락**. 가사는 짧아도 위험하니 쓰지 않는다
- [ ] 폰트·이미지 라이선스 증빙을 `출판/licenses.md`에 표로 보관
- [ ] 게임판(`docs/`, `scenario/`)과 인물명·나이·시간선 충돌 확인

## 6. 출간 후 (선택)

- 브런치스토리에 **상황 01~03만** 연재해 독자 반응과 검색 유입을 만든다. 전문 공개는 하지 않는다.
- 교보 eBook은 리뷰 수가 노출에 영향을 준다. 초기 10건 확보를 목표로 지인 대신 **읽은 사람에게만** 요청한다.
- 반응이 오면 그때 종이책 POD를 켠다. 미리 켤 이유가 없다.
- 게임판과 묶어 "소설을 읽고 게임에서 선택해보기" 크로스 홍보 가능.
