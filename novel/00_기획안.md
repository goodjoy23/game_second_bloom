# 기획안

## 한 문장 소개

마흔 넘어 만난 두 사람이 같은 하루를 각자 적었더니, 서로 다른 두 권의 일기가 되었다.

## 이 책이 파는 것

중년 독자가 돈을 내는 이유는 "설렘"이 아니라 **해석의 어긋남**이다.
젊은 연애 소설은 사건이 팔리고, 중년 연애 소설은 **같은 사건을 왜 다르게 읽었는가**가 팔린다.

그래서 모든 회차는 한 쌍이다.

```
[상황 03] 답장이 늦은 밤
  ├─ 창근의 시선 : 답장이 없어서 화면을 껐다 켰다
  └─ 인선의 시선 : 답장을 쓰다 지웠다, 세 번
```

독자는 창근 편을 읽고 "저 사람 왜 저래" 하다가, 인선 편에서 "아…" 한다.
그리고 마지막 **어긋남 노트**에서 "그래서 나는 뭘 해야 하지"를 가져간다.

이 세 번째가 없으면 독자는 공감만 하고 책을 덮는다. 어긋남 노트는 그 상황에서 작동한 심리·행동 기제를 이름 붙여 설명하고, 실제로 입에서 나올 수 있는 문장과 하지 말아야 할 것 하나를 남긴다. 양식과 금지 사항은 [어긋남 노트 설계](06_어긋남노트_설계.md)에 있다.

이 구조 덕분에 책의 매대가 하나 늘어난다. 소설로만 두면 한국소설 하나지만, 노트가 있으면 에세이와 관계 실용서 독자에게도 닿는다.

## 인물

### 이창근 (남, 화자 "나")

| 항목 | 내용 |
|---|---|
| 나이 | 50대 초반 (인선보다 서너 살 위) |
| 상태 | 혼자 산 기간이 길다. 생활은 정돈돼 있고 감정은 정돈돼 있지 않다 |
| 사랑의 방식 | 말하기 전에 처리한다. 고쳐주고, 사주고, 데려다준다 |
| 두려움 | 쓸모없어지는 것. 필요 없어지면 떠날 거라고 믿는다 |
| 시작 믿음 | 사랑하면 말 안 해도 알아서 해줘야 한다 |
| 마지막 변화 | "어디까지 해주면 좋겠어요?"라고 **묻는다** |

### 이인선 (여, 48세, 직장인)

| 항목 | 내용 |
|---|---|
| 직업 | 회사원. 실무를 오래 한 중간관리자. 회사에서는 결정을 잘한다 |
| 상태 | 자기 삶을 혼자 굴려왔다. 부모·건강·노후를 혼자 계산한다 |
| 사랑의 방식 | 폐가 될까 봐 먼저 말하지 않는다. 대신 오래 기억한다 |
| 두려움 | 기대는 순간 삶의 주도권을 잃는 것 |
| 시작 믿음 | 내 짐은 내가 져야 관계가 오래 간다 |
| 마지막 변화 | 필요한 도움 / 원치 않는 도움 / 혼자 할 일을 **구체적으로 말한다** |

두 사람의 결함은 대칭이다. 창근은 묻지 않고 하고, 인선은 말하지 않고 참는다.
처음엔 완벽하게 맞물리고, 나중엔 그것 때문에 부서진다.

## 주제문

사랑은 상대의 삶을 대신 짊어지는 일이 아니라, 상대가 자기 삶을 계속 살도록 곁을 내어주는 일이다.

## 톤

- 미화하지 않는다. 중년의 연애에는 약봉지, 대출 잔액, 부모의 병원, 전 배우자, 자녀가 같이 온다.
- 냉소하지 않는다. "이 나이에 무슨"이라는 문장은 쓰지 않는다.
- 야하지 않게, 그러나 몸을 지우지 않는다. 중년의 몸은 부끄러움과 다정함이 같이 있는 자리다.
- 교훈으로 끝내지 않는다. 각 편의 마지막 문장은 **정리가 아니라 잔상**이다.

## 분량과 판형

| 항목 | 기준 |
|---|---|
| 1편 분량 | 공백 포함 2,500~3,500자 |
| 편 수 | 30편 (15상황 × 2시선) + 어긋남 노트 15편 + 프롤로그 + 에필로그 |
| 어긋남 노트 | 편당 900~1,300자, 15편 합계 약 15,000자 |
| 총 분량 | 약 100,000~115,000자 |
| 판형 | A5 (148×210) 또는 신국판 (152×225) |
| 예상 쪽수 | 300~340쪽 |

첫 책으로 부담되면 **1~12상황(24편)까지만 1권**으로 내고 13~15상황은 2권 또는 개정판으로 넘긴다.
