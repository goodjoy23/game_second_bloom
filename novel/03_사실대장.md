# 사실 대장 (Fact Ledger)

두 시선이 공유하는 단 하나의 사실. **여기에 없는 사실은 원고에 쓰지 않는다.**
상황을 쓰기 전에 이 표를 먼저 채운다.

## 작성 양식

### 상황 NN. 제목

| 항목 | 내용 |
|---|---|
| 날짜/계절 | |
| 장소 | |
| 그날의 날씨·빛 | |
| 소품 (반복 등장할 물건) | |
| 실제로 오간 대사 | 1. "…"  2. "…"  3. "…" |
| 창근이 한 행동 | |
| 인선이 한 행동 | |
| 창근이 **못 본 것** | |
| 인선이 **말하지 않은 것** | |
| 독자가 이 상황에서 알게 될 새 사실 | |

## 상황 01. 다시 연락한 이유

| 항목 | 내용 |
|---|---|
| 날짜/계절 | 4월 셋째 주 목요일 저녁 |
| 장소 | (창근) 집 주방 식탁 / (인선) 퇴근길 지하철 |
| 그날의 날씨·빛 | 해가 길어지기 시작한 저녁, 여덟 시인데 아직 파랬다 |
| 소품 | 창근의 낡은 휴대폰, 인선의 접힌 우산 |
| 실제로 오간 대사 | 1. "지난번에 두고 가신 우산, 아직 갖고 있습니다." 2. (30분 뒤) "버리셔도 됐는데요." 3. "버리기엔 멀쩡해서요." |
| 창근이 한 행동 | 문장을 다섯 번 고쳐 쓰고 보냈다. 보내고 휴대폰을 엎어놨다 |
| 인선이 한 행동 | 지하철에서 읽고, 내려서 답했다 |
| 창근이 못 본 것 | 인선이 그 30분 동안 답장 초안을 썼다 지웠다 |
| 인선이 말하지 않은 것 | 우산을 일부러 두고 왔다는 것 |
| 새 사실 | **우산은 실수가 아니었다** |

> 이 한 줄(`우산은 실수가 아니었다`)이 상황 01 인선 편의 존재 이유다.
> 상황마다 이런 문장이 하나씩 있어야 한다. 없으면 그 상황은 아직 쓸 준비가 안 된 것이다.
