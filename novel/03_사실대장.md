# 사실 대장 (Fact Ledger)

두 시선이 공유하는 단 하나의 사실. **여기에 없는 사실은 원고에 쓰지 않는다.**
상황을 쓰기 전에 이 표를 먼저 채운다.

## 작성 양식

### 상황 NN. 제목

| 항목 | 내용 |
|---|---|
| 날짜/계절 | |
| 장소 | |
| 그날의 날씨·빛 | |
| 소품 (반복 등장할 물건) | |
| 실제로 오간 대사 | 1. "…"  2. "…"  3. "…" |
| 창근이 한 행동 | |
| 인선이 한 행동 | |
| 창근이 **못 본 것** | |
| 인선이 **말하지 않은 것** | |
| 독자가 이 상황에서 알게 될 새 사실 | |

## 시간선

- 2020년 무렵 앱에서 첫 연락. 지금 기준 약 6년 전
- 첫 연락에서 고백까지 약 1년
- 그 사이 냉삼집 첫 만남, 연락 공백기 반복
- 어느 쌀쌀한 날 고백, 대답 없이 헤어짐, 이후 유야무야 1일

---

## 상황 01. 앱에서 먼저 말을 건 날

| 항목 | 내용 |
|---|---|
| 날짜/계절 | 6년 전 |
| 장소 | (창근) 집 / (인선) *본인 작성* |
| 소품 | 만남 어플 프로필, 카카오톡 |
| 창근이 먼저 연락한 이유 | 나이가 비슷하고, 사는 지역이 가깝고, 자녀 상황이 비슷해서. 낭만이 아니라 조건이었다 |
| 오간 대화 | 첫 인사와 짧은 이야기 몇 마디 (구체적 문장은 두 사람이 같이 복원) |
| 창근이 한 행동 | 먼저 말을 걸었다. 연애를 많이 안 해봐서 책에서 배운 대로 했다 |
| 인선이 한 행동 | 답을 했다 |
| 창근이 **못 본 것** | 인선은 술김에 가입한 것이었다. 외로워서가 아니었다 |
| 인선이 말하지 않은 것 | *본인 작성* |
| 새 사실 | **인선은 애초에 누굴 만나려고 거기 있던 게 아니었다** |

> 이 한 줄이 상황 01 인선 편의 존재 이유다. 창근은 이 사실을 한참 뒤에야 안다.

## 상황 02. 씹힌 2주

| 항목 | 내용 |
|---|---|
| 날짜/계절 | 상황 01 직후, 이후 여러 번 반복 |
| 사실 | 대화가 끝나면 1~2주 연락이 없었다. 답이 늦거나 오지 않았다 |
| 창근이 한 행동 | 기다렸다. 무시인가 싶었다. 정리하려다 또 이어갔다 |
| 인선이 한 행동 | *본인 작성 — 그 2주 동안 무엇을 하고 있었는지* |
| 창근이 **못 본 것** | *본인 작성* |
| 새 사실 | *본인 작성 — 답하지 않은 것이 거절이었는지 아닌지* |

## 상황 03. 냉삼집, 첫 만남

| 항목 | 내용 |
|---|---|
| 장소 | 냉동삼겹살집 |
| 사실 | 첫 대면. 술을 많이 마셨고 인선은 첫날부터 취했다 |
| 창근이 한 행동 | *채울 것 — 데려다줬는지, 무엇을 했는지* |
| 인선이 한 행동 | 취했다 |
| 창근이 **못 본 것** | *채울 것* |
| 인선이 말하지 않은 것 | *본인 작성 — 왜 그렇게 마셨는지* |
| 새 사실 | *본인 작성* |

## 상황 04. 아무것도 아닌 1년

| 항목 | 내용 |
|---|---|
| 기간 | 첫 만남 이후 약 1년 |
| 사실 | 연인도 친구도 아닌 상태로 지냈다. 연락은 이어졌다 끊겼다 했다 |
| 창근이 한 행동 | 관계를 정의하지 않고 기다렸다 |
| 인선이 한 행동 | *본인 작성* |
| 새 사실 | *본인 작성 — 그 1년을 본인은 무엇이라고 생각하고 있었는지* |

## 상황 05. 쌀쌀한 날, 대답 없는 고백

| 항목 | 내용 |
|---|---|
| 날짜/계절 | 쌀쌀한 날 |
| 장소 | 같이 걷던 길 (운동 삼아) |
| 사실 | 창근이 사귀자고 했다. 인선은 대답하지 않았다. 그날은 그냥 헤어졌다 |
| 이후 | 유야무야 1일이 됐다. 시작한 날짜가 명확하지 않다 |
| 창근이 **못 본 것** | *채울 것 — 대답 없음을 무엇으로 읽었는지* |
| 인선이 말하지 않은 것 | *본인 작성 — 그때 왜 대답하지 않았는지* |
| 새 사실 | *본인 작성* |

> 이 책에서 가장 이상한 시작이다. 시작한 날이 없는 연애를 어떻게 기념할 것인가는 뒤의 상황(기념일 충돌)으로 이어진다.
