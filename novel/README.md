# 《우리는 같은 날을 다르게 적었다》 (가제)

중년의 연애를 남자와 여자, 두 개의 1인칭으로 각각 기록하고 나중에 교차 배열해 한 권으로 합치는 작품.

- 남자 화자: **이창근** — "나"
- 여자 화자: **이인선** (48세, 직장인)
- 형식: 소설과 에세이의 중간. 실제 감정을 소재로 하되 인물·지명·직장은 변형한다.
- 최종 목표: 교보문고 퍼플(PubPle) eBook **무료 출간**, 종이책 POD는 선택.

## 게임판과의 관계

`docs/`, `scenario/`의 게임판 정사(강민우·윤서정)와 **인물명이 다르다**. 두 갈래 중 하나를 선택한다.

1. **분리 운영(현재 기본값)** — 게임은 강민우/윤서정, 책은 이창근/이인선. 서로 간섭하지 않는다.
2. **통합** — 책 출간 후 게임 인물명을 이창근/이인선으로 맞추고 게임을 "같은 세계의 다른 매체"로 둔다.

결정 전까지는 1번을 유지한다.
